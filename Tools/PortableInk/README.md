# PortableInk lab

A dependency-free JavaScript/Canvas **test editor**, not an Android or Windows product app. It reads MiNote schema-v2 documents, translates or deletes strokes by UUID, appends editable pen strokes, and exports JSON. PDF metadata remains intact; the PDF background is not rendered.

From the repository root:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765/Tools/PortableInk/`. Choose **샘플 열기**, select a stroke, enter movement in page points, or choose **새 펜으로 그리기** and drag. Zoom changes the viewport only. **JSON 다운로드** requests a separate file and also exposes its exact JSON in a read-only text area. If a browser does not provide file downloads, save this output as a `.json` file. MiNote's current production app does not yet offer a JSON import UI; the reverse path uses bundled fixtures and temporary stores in automated iPad tests.

```sh
node --test Tools/PortableInk/*.test.mjs
node Tools/PortableInk/roundtrip.mjs --check
```

`document.mjs` is independent of the DOM and Apple frameworks. Failed loads/commands preserve the current document. Unknown fields, unsupported tools/versions, invalid geometry and integer values beyond JavaScript's safe range are rejected instead of rewritten. Canvas approximates variable point size, alpha and affine transforms; PencilKit texture, curves and marker compositing are not pixel-identical. Pressure, tilt, timing and seed are retained as data.

Shared fixtures live in `Packages/MiNoteCore/Tests/MiNoteCoreTests/Fixtures/PortableInk`:

- `source.json` / `source.pdf`: generated by real PencilKit and raw PDF fixture code.
- `edits.json` / `edited.json`: deterministic commands and actual JavaScript output, revision 40→43. Regenerate with `node Tools/PortableInk/roundtrip.mjs` and review the changes.
- `browser-edited.json`: actual UI output after moving 101 by (12,-8), deleting 103 and drawing a new pen stroke. Its UUID and sampled points differ from the deterministic CLI fixture.

On 2026-10-03, Codex IAB showed those edits and output, but its download event timed out. The browser fixture was saved from the visible read-only output. Native file download in a general browser remains unverified. See `docs/PROGRESS.md` for Swift/iPad reverse-edit evidence and remaining limits.

The gesture controller binds input to its starting document/page and scale. Document replacement, page/zoom changes, mode exit and lost capture cancel it; secondary pointer events cannot cancel the primary stroke. Tests run the actual UI handlers with DOM/canvas boundaries faked. The final browser test reopened `browser-edited.json`, changed zoom 100→200→100%, and confirmed exported text exactly unchanged.
