# PortableInk fixtures

`source.json` is generated by `MiNoteTests/PortableInkTests.testGeneratePencilKitFixture` from real PencilKit strokes with fixed UUIDs and times. The test exports it and `source.pdf` into the simulator test app's Documents/PortableInkGenerated directory. Copy those files here with `simctl get_app_container`.

`edited.json` will be generated by the independent JavaScript tool from `source.json` and `edits.json`. Both Swift test bundles consume the same files. These fixtures never replace the user's current note.

## M1-B v3 fixture

`PortableInkTests.testGenerateV3PencilKitFixture`가 iPad simulator의 `Documents/PortableInkGenerated/multi-source.json`에 기록한다. Native pen/marker/transform/seed에 두 PDF 자산 ID·삭제 페이지·grid/bookmark metadata를 결합했다. PDF bytes는 기존 source.pdf를 각 자산 UUID path로 복사한다. `multi-edited.json`은 같은 edits.json을 실제 JS 명령으로 처리한 출력이며 v2 fixture는 유지한다.

Native `testIndependentV3RoundTripPreservesPagesAssetsAndEditableInk`는 JS 결과 재편집/Undo/Redo/저장/재열기와 모든 자산/삭제 페이지/미수정 page metadata를 검증한다.
## M2-A lasso round trip

`lasso-source.json` and `lasso-moved.json` were generated by the actual app's
`SelectionSessionTests.testGenerateActualLassoMovedV3Fixture` on iPadOS 18.6.
The v3 note retains two PDF assets, grid paper, bookmarks and a deleted page.
The session selects the single stroke on PDF page 11 and translates it by
document `(30, -15)` at revision 40 → 41, preserving its UUID and all point data.
Only the test's `PortableInkGenerated` output files were recovered from the
simulator. Existing user/library data was not seeded or removed.

`node Tools/PortableInk/roundtrip.mjs --lasso` consumes that app result and the
existing `edits.json` to produce `lasso-edited.json` at revision 44. Node also
independently computes the app's `(30, -15)` command and compares its full value.
The core codec and iPad then read the independent output, add/erase ink, exercise
Undo/Redo and save/reopen it. `--lasso --check` checks the frozen JS output.
